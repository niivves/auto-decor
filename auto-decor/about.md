# Auto Decor Mod

Created by **Nives**.

Adds decoration to the layout you already built. It never builds structures:
it recolours your blocks and adds decor pieces on your existing blocks, edges
and spikes.

1. Open the level editor and press **Decor**.
2. Pick a style and watch the before/after preview.
3. Select some deco objects in the editor and press **Overlay / Edge / Glow /
   Backdrop** to tell the mod which pieces to use for that style.
4. Press **Decorate!**. Use **Undo last** to remove what was added.
